# Décisions d'architecture (ADR)

Chaque ADR fige une décision technique importante : son contexte, les options envisagées, le choix fait et ses conséquences.
Un ADR passe par une pull request relue. Son statut passe de **Proposé** à **Accepté** juste avant le merge. Une décision remplacée garde son fichier, avec le statut **Remplacé par ADR-XXXX**.
