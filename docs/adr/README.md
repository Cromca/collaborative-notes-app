# Décisions d'architecture

Les décisions techniques importantes de notes-app sont consignées ici sous forme d'ADR (Architecture Decision Record). Un ADR accepté n'est jamais réécrit : si la décision change, on écrit un nouvel ADR et on passe l'ancien en « Remplacé par ADR-00XX ».

Chaque ADR est validé par pull request : il est ouvert en statut « Proposé » et passe en « Accepté » juste avant le merge.
