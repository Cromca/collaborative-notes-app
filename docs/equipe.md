# Qui fait quoi

La référence pour les rôles de l'équipe, la matrice RACI et le tableau « Où trouver quoi » est la page Wiki **[Qui fait quoi](https://github.com/Cromca/collaborative-notes-app/wiki/Qui-fait-quoi)**.

Ce fichier n'est qu'un point d'entrée : il ne contient pas de copie de la matrice, pour qu'il n'y ait jamais deux versions concurrentes. Les changements de rôles se discutent dans une issue ou une PR, puis sont reportés dans le Wiki.
