# API notes-app

API Express de notes-app. Le guide complet (installation, routes, exemples `curl`, erreurs) est dans [../README.md](../README.md).

```sh
npm ci
npm start
npm test
```

L'API écoute sur `http://localhost:3000` (variable `PORT`). Les tests démarrent un serveur sur un port libre avec un fichier de notes temporaire.
